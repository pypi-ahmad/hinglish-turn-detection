Make the experiment usable

Inference repeats training preprocessing, loads the stored threshold, and returns enough information to inspect a decision.

audio file or array
  to validate and resample
  to crop final 8 seconds
  to feature extractor and model
  to probability and threshold
  to decision and latency

TurnDetector owns this path. The Gradio app adds upload, microphone recording, waveform display, confidence, examples, and a queue.

Latency claims need boundaries

The selected run measured 24.71 ms CPU and 4.81 ms GPU for warm model forward only. Those numbers exclude feature extraction and model loading. The production API separately reports end-to-end request latency.

Deployment

The public Space runs Gradio on ZeroGPU. Its README supplies Space metadata, and Git LFS stores the checkpoint. A healthy deployment requires more than a green status: inspect startup logs and call the real API with audio.

Public input risk

The app validates decoded audio, but the repository still documents a missing upload-size limit. Cropping after decoding does not prevent a very large upload from consuming resources first.

Trace it in code

  • src/inference.py: input normalization, model load, threshold, batch inference
  • app.py: interface and prediction callback
  • requirements.txt: Space runtime dependencies
